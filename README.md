# storyBox_backend

Fastify-based Node.js API server for the StoryBox audio streaming platform.

## 🛠️ Tech Stack
- **Framework**: Node.js + Fastify
- **Database**: MongoDB (via Mongoose)
- **Language**: TypeScript

## 🚀 Getting Started

### 📋 Prerequisites
- **Node.js**: v20 or later
- **MongoDB**: A running local or remote instance of MongoDB.

### ⚙️ Installation & Running
1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure `.env` using `.env.example`.
3. Start in development mode:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
5. Start built production server:
   ```bash
   npm run start
   ```
